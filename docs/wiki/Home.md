# Tokiwagi UI Wiki

Tokiwagi UIの環境構築、MIT対象コンポーネントの使い方、検証、開発参加、ライセンスを案内します。概要と技術スタックは[リポジトリのREADME](https://github.com/HikariTakahashi/tokiwagi-ui/blob/main/README.md)を参照してください。

## 初めて利用する方へ

1. [License](https://github.com/HikariTakahashi/tokiwagi-ui/wiki/License)でMIT対象とブランド除外を確認します。
2. [Setup](https://github.com/HikariTakahashi/tokiwagi-ui/wiki/Setup)でソースを取得し、開発環境を準備します。
3. [Usage](https://github.com/HikariTakahashi/tokiwagi-ui/wiki/Usage)で利用するフレームワークの導入方法を確認します。
4. 開発に参加する場合は[Testing](https://github.com/HikariTakahashi/tokiwagi-ui/wiki/Testing)と[Contributing](https://github.com/HikariTakahashi/tokiwagi-ui/wiki/Contributing)を確認します。
