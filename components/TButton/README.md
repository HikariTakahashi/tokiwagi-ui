# TButtonの利用ルール

## 概要

フォームやダイアログで操作を実行するReact・Vue・Astro共通のボタンです。文字ラベルと、必要に応じて先頭の装飾アイコンを表示します。

## 使用場面

保存、登録、確認など、画面内の操作に使います。既定の `type` は `button` です。フォームを送信する場合は `type="submit"` を指定してフォームの送信イベントで処理します。

## 状態の表し方

`tone` はニュートラルと7色のプライマリーから選びます。既定は `neutral` です。プライマリー色では、通常・ホバー・押下の背景にそれぞれ同じ色の基準・`-hover`・`-active` トークンを使い、文字と装飾アイコンは白で表示します。キーボードフォーカスは輪郭で示します。`disabled` で操作を無効にするとニュートラルの無効色になります。保存中・成功・失敗の状態は利用側が管理し、必要な案内を文言で伝えます。

## 使用しない場面

画面遷移はTLinkを使います。ヘッダー内の操作や選択状態のある切り替えには、該当するヘッダー用コンポーネントを使ってください。

## 表示とアクセシビリティ

Reactのchildren、Vue・Astroの既定スロットに「保存する」など、操作の結果が伝わる文字ラベルを入れます。ボタンやリンクを内容に入れないでください。先頭の `leadingIcon` は32pxの装飾として扱い、読み上げ名はラベルから取得します。Tabでフォーカスし、EnterまたはSpaceで操作できます。高さは50px以上で、文言が収まらない場合は折り返して高さが伸びます。幅は利用側の `class`（Reactは `className`）などで指定します。Astroは静的なボタンを出力し、操作の処理はフォームや利用側のscriptで接続します。
