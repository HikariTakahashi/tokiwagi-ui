# TText

## 概要

本文・補足説明・短い文言の書体、サイズ、太さ、行高、色を揃える静的なテキスト表示部品です。React・Vue・Astroで同じ設定と表示ルールを使います。

[使用例を見る](../../src/stories/TText.stories.ts)

## 使用場面

- タスク名、説明文、メモ、補足説明、状態を伝える文章に使います。
- 本文はmd（標準16px）、補足はsm（標準14px）、大きい本文はlg（標準18px）を使います。サイズはremで定義し、利用者の文字サイズ設定に追従します。
- 段落にはp、文中の一部にはspanを選びます。既定はspanです。
- 640px・1024px以上でサイズを切り替えられます。行高は既定1.5で、必要な場合だけ倍率を指定します。

## 状態の表し方

- 本文はdefault、補足説明はmuted、親と同じ色はinheritを使います。
- success・warning・error・infoは、既存の状態色の文字用トークンを使います。「保存に失敗しました」などの文言も併記し、色だけで意味を伝えません。
- 白・neutral-50背景の固定toneは通常文字のコントラスト4.5:1以上を検証します。任意の背景や継承色は利用側で確認してください。
- 太さ、斜体、下線、取り消し線は見た目の設定です。内容の重要性にはstrong、強調にはemなど、意味に合う子要素を使います。

## 使用しない場面

- 見出しは文書の階層に合うh1〜h6で表します。
- クリック処理やフォーカス可能な属性を付けるだけで、文章をボタンやリンクの代わりにしません。移動にはa、操作にはbuttonを使います。
- コピー、編集、ツールチップ、記事全体の装飾はTTextの責任に含めません。

## 表示とアクセシビリティ

- 書体は共通フォントトークンを使い、日本語と各OSの代替フォントを維持します。余白は0で、配置は親が担当します。
- 長い日本語とURLは折り返します。通常は改行と連続空白をまとめ、pre-lineで改行、pre-wrapで改行と空白を保持します。
- truncateは1行、lineClampは指定行数で省略し、全文はDOMに保持します。両方の同時指定はエラーです。親などで幅を制限し、全文を詳細画面などで確認できるようにします。
- 省略は内側のリンクも隠し得るため、操作要素を含む文章の省略は避けてください。
- inheritを指定すると、書体・サイズ・太さ・行高を親から継承します。明示したサイズ・太さ・行高は優先されます。色の継承はtoneで別に指定します。
- id・aria-*・data-*・class・styleなどを外側の要素へ転送します。通常表示にフォーカスや読み上げ用のroleは追加しません。
- Reactのchildren、Vue・Astroのデフォルトslotで内容を渡します。文字列をHTMLとして解釈しません。Astroの静的表示にクライアントJavaScriptは不要です。
