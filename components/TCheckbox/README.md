# TCheckbox

## 概要

カレンダーなどの項目の選択を切り替えるチェックボックスです。入力欄と項目名のどちらからでも操作できます。

[使用例を見る](../../src/stories/TCheckbox.stories.ts)

## 使用場面

- 複数のカレンダーから表示するものを選ぶ。
- 一覧の各項目を選択し、親のチェックボックスで一括操作する。

## 状態の表し方

| 状態 | 表示 |
| --- | --- |
| 未選択 | 枠と白い背景を表示します。 |
| 選択済み | 色付きの背景にチェックを表示します。 |
| 一部選択 | 色付きの背景に横線を表示します。 |
| 無効 | 淡い配色にし、チェックまたは横線があれば維持します。 |
| エラー | 太い枠と「エラー」の文言を伴うメッセージを表示します。 |

一括操作では、すべて選択済みであれば親を選択済み、一部なら一部選択、すべて未選択なら未選択にします。対象項目と親の状態は利用側で管理します。

## 使用しない場面

候補のうち必ず1つを選ぶときはラジオボタンや単一選択欄を使います。その場で処理を実行する操作にはボタンを使います。

## 表示とアクセシビリティ

- チェックの枠は32px四方です。項目名を指定し、単独のアイコンとして使う場合は `aria-label` または `aria-labelledby` で用途を伝えます。
- フォーカス中は枠の外側にフォーカスリングが出ます。Tabで移動し、Spaceで切り替えます。
- 補足・エラーは入力に関連付けられます。色を変更しても、選択状態はチェックまたは横線で見分けられます。
- 関連する入力は `fieldset` と `legend` でまとめ、同じ文書内で入力IDが重複しないようにします。

## 関連コンポーネントと使い分け

- [TSelect](../TSelect/README.md) は候補の中から1つを選ぶ入力です。
- [TButton](../TButton/README.md) は処理を開始する操作に使います。
- [カラーの使用ルール](../../src/stories/colors.mdx) は7色のプライマリーの選び方を示します。
