# TIconの利用ルール

[使用例を見る](../../src/stories/TIcon.stories.ts)

## 概要

全329種の汎用アイコンを、共通のサイズと色で表示する装飾用コンポーネントです。図柄の意味は併記テキストで、操作の目的は親のbuttonやlinkで伝えます。ブランドロゴは対象に含みません。

## 使用場面

- 通知一覧への導線にbell、タスク追加にplusなど、操作の目的を視覚的に補う場合。
- テキストと組み合わせて、完了・通知停止などの状態を示す場合。
- 一覧やナビゲーションで、項目の種類を見分けやすくする場合。

図柄は[アイコン一覧](../../src/stories/icons.mdx)と各アイコンの個別ルールから選びます。bellの詳細ルールは確定済み、ほかは詳細ルール案です。

## 状態の表し方

- `-off`は図柄が表す状態です。たとえば通知停止と、ボタンのdisabledによる操作不可は区別します。
- 完了・警告などの状態は文言でも伝え、色や図柄だけに依存しません。
- ホバー・押下・フォーカス・無効状態、クリック処理と操作領域は親要素が担います。

## 使用しない場面

- アイコンだけで操作名や重要な状態を伝える場合。
- TIcon自体をフォーカス可能なボタンやリンクとして扱う場合。
- ブランドロゴの表示、原本にない図柄への変形、線幅・縦横比の変更。
- 16pxでは細部を判別できない図柄を、そのまま小さく配置する場合。

## 表示とアクセシビリティ

- サイズは16・20・24・32pxから選び、基本は24pxです。16pxで判別しにくい場合は24px・32pxに上げ、ラベルを併記します。全図柄の16px利用を一律には推奨しません。
- 32×32のviewBox、原本の座標・線幅・縦横比を保持します。配置用クラスでサイズや線幅を上書きしません。
- 黒い線と塗りをcurrentColorに変換し、透明な塗りと白いクリッピングは保持します。既定の色は親の文字色を継承します。
- 色は既存トークンを参照します。通常の色背景には同色の`-on`、淡い背景には`-on-subtle`を組み合わせます。背景との組み合わせは[カラーの使用ルール](../../src/stories/colors.mdx)に従います。
- SVGは`aria-hidden="true"`・`focusable="false"`で装飾として扱います。意味は併記テキストで伝え、アイコンだけの操作には親のbuttonやlinkに「通知一覧を開く」など目的が分かる読み上げ名を付けます。
- 操作領域・キーボード操作・フォーカス表示は親が確保します。サイズの指定だけでは操作領域は確保されません。
