# TLogoの利用ルール

[使用例を見る](../../src/stories/TLogo.stories.ts)

## 概要

Tokiwagi UIのブランドロゴを、原本の固定配色と余白を保って単体表示するコンポーネントです。名称やリンクは親側で組み合わせます。

## 使用場面

- 同じ画面内でTokiwagi UIの名称を確認できる場所での、ロゴ単体の表示。基本は名称と併記します。
- 既に名称を表示しているヘッダーなどで、ロゴを添える場合。
- 独自のレイアウトで名称やホームリンクと組み合わせる場合。固定名称との標準的な横並びにはTBrandを使います。

## 状態の表し方

- ロゴは静的なブランド表示です。選択・成功・警告・無効などの状態を配色変更で表しません。
- リンクとして使う場合のホバー・押下・フォーカスは親のリンクが担います。ロゴの固定配色と余白は維持します。

## 使用しない場面

- 通知・タスクなどの汎用的な操作や状態のアイコンとして使う場合。
- 図形幅を32px未満にする、縦横比を変える、切り抜く、ロゴの色を親の文字色に合わせる場合。
- 周囲の余白を削る、ロゴ領域に別の要素を重ねる場合。
- 単独表示で名称を伝える必要があるのに、装飾扱いにして読み上げ名をなくす場合。

## 表示とアクセシビリティ

- 図形幅は32・64・128pxから選びます。最小サイズは32×32 CSS pxです。小さい画面でもCSSで縮小しません。
- 四辺に図形幅の1/4の余白を確保し、余白を含む領域は図形幅の1.5倍の正方形です。

| 図形幅 | 四辺それぞれの余白 | 占有領域 |
| --- | --- | --- |
| 32px | 8px | 48×48px |
| 64px | 16px | 96×96px |
| 128px | 32px | 192×192px |

- 原本の固定配色を維持し、親の文字色は画像に継承しません。余白には`--tkw-color-neutral-0`の背景を確保します。配置先はneutral-0・neutral-50などの明るい背景を基本とし、[ロゴ原本の使用ルール](../../icons/logo/README.md)に従います。
- 単独表示ではalt「Tokiwagi UI」で名称を伝えます。名称併記や名前付きリンクではdecorativeを指定して空altにし、重複読み上げを避けます。
- TLogo自体は操作要素ではありません。ホームリンクでは親に「Tokiwagi UI ホーム」など目的が分かる名前を付け、操作領域とキーボードフォーカスを確保します。

## 関連コンポーネントと使い分け

- [TBrand](../TBrand/README.md)：ロゴと固定名称「Tokiwagi UI」を標準の間隔で併記します。
- [TIcon](../TIcon/README.md)：操作や状態を補う汎用アイコンを表示します。ブランドロゴは含みません。
- [ロゴ原本の使用ルール](../../icons/logo/README.md)：ブランド資産としての表示方針と原本を確認できます。
