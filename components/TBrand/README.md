# TBrandの利用ルール

[使用例を見る](../../src/stories/TBrand.stories.ts)

## 概要

ブランドロゴと固定名称「Tokiwagi UI」を横並び・縦中央揃えで表示する、静的なブランド表示コンポーネントです。内部でTLogoを装飾として使い、名称をテキストで一度だけ伝えます。

## 使用場面

- ヘッダーなどでロゴと名称をセットで示す場合。
- 親のリンクと組み合わせ、ブランド表示をホームへの導線にする場合。
- ロゴ・名称の書体や間隔を揃えて配置する場合。

## 状態の表し方

- ブランド表示自体に選択・無効などの操作状態を持たせません。
- リンク先・操作名・ホバー・押下・フォーカスは親のa要素が担います。状態表示のためにロゴを変色・変形しません。
- 名称の色は親の文字色を継承します。背景に対する読みやすさは親で確保します。

## 使用しない場面

- 別の製品名、任意の文字列、ロゴだけを表示する場合。
- 名称の大きさや字間、ロゴとの間隔を独自に変更する場合。
- 狭い領域に収めるためにロゴと名称を縮小・折り返しする場合。
- TBrand自体にリンク先やクリック処理を持たせる場合。

## 表示とアクセシビリティ

- ロゴの図形幅は32・64・128pxから選びます。固定配色と四辺の余白は[TLogoの利用ルール](../TLogo/README.md)に従います。
- 名称は「Tokiwagi UI」で固定です。書体はInter・Noto Sans JP・システムフォントの順を使い、16px・太さ600・行高1.5・通常の字間で表示します。フォントの配信は利用側が担当します。
- ロゴ領域と名称の間隔は8pxです。外側のpaddingは追加しません。名称の右側の余白と、リンクに必要な操作領域は親で確保します。
- 全幅は「図形幅×1.5＋8px＋名称の実測幅」、高さは「図形幅×1.5」です。図形幅を変えても名称は16pxのままです。小さい画面でも内部の寸法や余白を上書きせず、収まる配置を選びます。
- 内部TLogoは空altで、名称をテキストとして一度だけ読み上げます。静的表示自体にはフォーカスを当てません。
- ホームリンクにする場合は親のa要素で包み、読み上げ名を「Tokiwagi UI ホーム」にします。キーボード操作とフォーカス表示も親が確保します。

## 関連コンポーネントと使い分け

- [TLogo](../TLogo/README.md)：ロゴ単体、または名称との独自レイアウトが必要な場合に使います。
- [TIcon](../TIcon/README.md)：操作や状態を補う汎用アイコンです。ブランド表示には使いません。
- [ロゴ原本の使用ルール](../../icons/logo/README.md)：ブランド資産の固定配色・余白・名称併記の方針を確認できます。
