# task

ファイル：`task.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`todo`、`checklist`、`タスク`、`作業`、`やること`

実行する作業やタスクの一覧を表す。

## 使用場面

- 「タスク一覧を開く」：操作対象と実行結果が分かる場所で使用する。
- 「タスク詳細を表示」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 未着手・進行中・完了は別の状態表示で示す。task の図柄だけで完了を表さない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- すべての予定、通知だけの設定、チェックボックスの選択印。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「タスク一覧を開く」など、図形名ではなく操作目的が分かる名前を付ける。
- タスク名と進行状態をテキストで示す。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`task-off`](?path=/docs/icons-task-off--docs)：タスク機能の停止・非表示。タスクゼロやタスク完了とは区別する。
- [`calendar`](?path=/docs/icons-calendar--docs)：日付・予定を表す。
- [`check`](?path=/docs/icons-check--docs)：枠のない選択・完了の印。
- [`task-bell`](?path=/docs/icons-task-bell--docs)：タスクに関する通知であることを図柄でも区別する場合に使う。
