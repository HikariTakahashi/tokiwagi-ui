# calendar-off

ファイル：`calendar-off.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`date`、`schedule`、`event`、`カレンダー`、`日付`、`予定`、`off`、`オフ`、`斜線`、`hidden`、`非表示`、`停止`

`calendar`に斜線を付けた図柄。カレンダー機能の停止・非表示。予定ゼロや日付未選択を意味しない。

## 使用場面

- 状態の表示：カレンダー機能の停止・非表示。予定ゼロや日付未選択を意味しない。
- 状態を変更する操作に添える場合は「カレンダーを表示」「カレンダー機能を再開」など実際の結果をラベルで伝える。状態表示と次の操作を同じ場所で混同させない。

## 状態の表し方

- カレンダー機能の停止・非表示。予定ゼロや日付未選択を意味しない。
- 通常の入口・操作は [`calendar`](?path=/docs/icons-calendar--docs) を使う。斜線を、処理成功・処理失敗・件数ゼロの共通記号にしない。
- `-off`は図柄の状態名であり、ボタンの disabled 属性や操作可否を自動的に決めない。状態を戻せる場合は、その操作を可能にする。

## 使用しない場面

- タスク完了、通知設定済み、時刻のみの入力。
- 理由を示さず、すべての操作不可ボタンを斜線付きに置き換えること。

## 表示とアクセシビリティ

- 「calendar-off」や「斜線付き」ではなく、停止・解除・制限の対象と状態をテキストで伝える。
- 切り替えを操作できる場合は実際の操作名と状態を伝える。利用制限の場合は、何が制限されているかと必要な理由を添える。
- 選択日を年月日で伝え、色だけで今日や選択日を区別しない。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`calendar`](?path=/docs/icons-calendar--docs)：通常の図柄。停止・制限を示さない入口や操作に使う。
- [`task`](?path=/docs/icons-task--docs)：実行する作業を表し、完了状態を意味しない。
- [`clock`](?path=/docs/icons-clock--docs)：時刻・所要時間を表し、通知設定の有無を意味しない。
- [`calendar-bell`](?path=/docs/icons-calendar-bell--docs)：予定に関する通知であることを図柄でも区別する場合に使う。
