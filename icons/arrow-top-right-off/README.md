# arrow-top-right-off

ファイル：`arrow-top-right-off.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`arrow`、`arrow-up-right`、`navigation`、`external-link`、`矢印`、`右上矢印`、`リンク`、`画面遷移`、`別ページ`、`外部リンク`、`off`、`オフ`、`斜線`、`移動不可`、`リンク先を利用できない`

右上矢印に斜線を付けた図柄。移動先を利用できない状態や、画面遷移の制限を表す。

## 使用場面

- 「リンク先を利用できません」など、移動先を利用できない状態を示す場所。
- 移動できない理由や再開条件を説明する文言に添える。

## 状態の表し方

- 移動先を利用できない理由を、アイコンに加えて文言で伝える。通信エラーや連携解除の意味を自動的に割り当てない。
- `-off`は図柄の状態名であり、リンクやボタンの操作可否を自動的に設定しない。操作を制限する処理と読み上げは利用側が担う。
- 状態は色だけに頼らず、文言・図柄・親の操作部品の状態で伝える。

## 使用しない場面

- 対象同士の関連付け、アカウント連携・連携解除、共有権限の変更、ファイルの添付。
- 予定の日時変更、並べ替え、アップロードなど、画面遷移以外の方向を持つ操作。
- アイコンだけで操作名や遷移先を説明すること。

## 表示とアクセシビリティ

- 図形名ではなく「リンク先を利用できません」など、対象と目的が分かるテキストを併記する。アイコンだけの操作には親のリンクやボタンに読み上げ名を付ける。
- TIconは装飾として扱う。フォーカス・ホバー・押下・操作可否・キーボード操作は親の操作部品が担う。
- 外部サイトや別タブへ移動する場合は、実際の挙動を必要に応じて文言でも伝える。
- サイズは16・20・24・32px、色は共通トークンを使う。32×32のviewBox、座標、線幅、縦横比を個別に変更しない。

## 関連アイコンと使い分け

- [`link-off`](?path=/docs/icons-link-off--docs)：鎖の図柄。対象同士の関連付け・連携と、右上矢印による画面遷移を区別する。
- [`arrow-top-right`](?path=/docs/icons-arrow-top-right--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合に使う。
