# sort-off

ファイル：`sort-off.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`order`、`reorder`、`並べ替え`、`ソート`、`表示順`、`off`、`オフ`、`斜線`、`inactive`、`未適用`、`利用不可`

`sort`に斜線を付けた図柄。並べ替えを適用していない状態。機能の制限を示す場合は理由を添える。

## 使用場面

- 状態の表示：並べ替えを適用していない状態。機能の制限を示す場合は理由を添える。
- 状態を変更する操作に添える場合は「解除する」「再開する」など実際の結果をラベルで伝える。状態表示と次の操作を同じ場所で混同させない。

## 状態の表し方

- 並べ替えを適用していない状態。機能の制限を示す場合は理由を添える。
- 通常の入口・操作は [`sort`](?path=/docs/icons-sort--docs) を使う。斜線を、処理成功・処理失敗・件数ゼロの共通記号にしない。
- `-off`は図柄の状態名であり、ボタンの disabled 属性や操作可否を自動的に決めない。状態を戻せる場合は、その操作を可能にする。

## 使用しない場面

- 絞り込み、検索、ドラッグ可能な場所の印。
- 理由を示さず、すべての操作不可ボタンを斜線付きに置き換えること。

## 表示とアクセシビリティ

- 「sort-off」や「斜線付き」ではなく、停止・解除・制限の対象と状態をテキストで伝える。
- 切り替えを操作できる場合は実際の操作名と状態を伝える。利用制限の場合は、何が制限されているかと必要な理由を添える。
- 現在の並べ替え項目と方向をテキストでも示す。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`sort`](?path=/docs/icons-sort--docs)：通常の図柄。停止・制限を示さない入口や操作に使う。
- [`filter`](?path=/docs/icons-filter--docs)：表示対象の絞り込み。
- [`grip-vertical`](?path=/docs/icons-grip-vertical--docs)：縦長のドラッグハンドル。
- [`sort-arrow-down`](?path=/docs/icons-sort-arrow-down--docs)：下向き矢印で、選択した並べ替え方向を示す。
