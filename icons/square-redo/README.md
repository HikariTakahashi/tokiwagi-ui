# square-redo

ファイル：`square-redo.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`box`、`rectangle`、`四角`、`四角枠`、`正方形`、`reapply`、`やり直し`、`再適用`

四角枠の図柄。取り消した操作を再び適用する、やり直しを表す。 枠の形そのものは重要度・操作可否・選択状態を意味しない。

## 使用場面

- 「やり直す」：操作対象と実行結果が分かる場所で使用する。
- 「取り消した編集をやり直す」：同じ部品では意味を固定し、別の操作を兼ねさせない。
- 同じ領域で四角枠の表現を採用する場合に使用する。枠付きアイコンを使うだけでボタンとしての役割を与えない。

## 状態の表し方

- 取り消し履歴に再適用できる操作がある場合に提供し、可能なら操作内容を示す。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。
- 成功・注意・失敗などの役割は、内容を説明する文言とセマンティックカラーで示す。枠の形だけで役割を変えない。

## 使用しない場面

- 通信の再試行、再読み込み、定期実行。
- 操作できない状態表示を、押せるボタンのように見せること。
- 枠の違いだけで、重要度・操作内容・選択状態を使い分けること。

## 表示とアクセシビリティ

- アイコンだけの操作には「やり直す」など、図形名ではなく操作目的が分かる名前を付ける。
- 「タイトル変更をやり直す」など対象の操作を示す。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`redo`](?path=/docs/icons-redo--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`undo`](?path=/docs/icons-undo--docs)：適用済み操作の取り消し。
- [`history`](?path=/docs/icons-history--docs)：過去の変更の閲覧。復元操作そのものとは区別する。
- [`repeat`](?path=/docs/icons-repeat--docs)：単発の再実行・再読み込み。
- [`circle-redo`](?path=/docs/icons-circle-redo--docs)：円枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
- [`triangle-redo`](?path=/docs/icons-triangle-redo--docs)：三角枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
