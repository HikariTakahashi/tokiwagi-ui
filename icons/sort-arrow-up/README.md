# sort-arrow-up

ファイル：`sort-arrow-up.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`order`、`arrow-up`、`並べ替え`、`ソート`、`上矢印`、`上方向`

上向き矢印で、選択した並べ替え方向を示す。

## 使用場面

- 「更新日時の逆順を表示」：操作対象と実行結果が分かる場所で使用する。
- 「優先度の並び順を切り替え」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 上向きだけで昇順・降順を決めない。対になる下向きと対象項目をそろえ、逆順の意味を文言で示す。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 上へのスクロール、アップロード、説明のない昇順・降順。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「更新日時の逆順を表示」など、図形名ではなく操作目的が分かる名前を付ける。
- 「更新日時：古い順」など実際の順序を伝える。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`sort-arrow-up-off`](?path=/docs/icons-sort-arrow-up-off--docs)：この方向の並べ替えが未適用・利用不可の状態。どちらかを文言で特定する。
- [`sort-arrow-down`](?path=/docs/icons-sort-arrow-down--docs)：下向き矢印で、選択した並べ替え方向を示す。
- [`sort`](?path=/docs/icons-sort--docs)：表示順の変更。
- [`chevron-top`](?path=/docs/icons-chevron-top--docs)：上方向への移動、展開中の領域の折りたたみを表す。
