# task-chevron-left

ファイル：`task-chevron-left.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`todo`、`checklist`、`タスク`、`作業`、`やること`、`arrow-left`、`previous`、`左矢印`、`左方向`、`前へ`

タスクを対象とする図柄。前の項目・期間・ページへの移動を表す。

## 使用場面

- 「タスク：前の項目へ移動」：同じ種類の対象内で前の項目・期間へ移動する。移動単位をラベルに含める。
- タスクとほかの対象が混在し、対象を図柄でも区別したい場所で使用する。タスク詳細の中など対象が明確な場所では、基本形の [`chevron-left`](?path=/docs/icons-chevron-left--docs) を優先する。

## 状態の表し方

- 操作・状態の適用範囲を示す。1件のタスクなのか、選択した複数件・一覧全体なのかをラベルや周辺文言で明示する。
- 対象の単位を明示し、移動できる範囲の端では操作部品の状態で制限を伝える。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 操作の取り消し、ログアウト、パネルを閉じる操作の曖昧な代用。
- 操作できない状態表示を、押せるボタンのように見せること。
- タスクに限定されないアプリ全体の操作や、別の種類の対象への操作。

## 表示とアクセシビリティ

- 「タスク：前の項目へ移動」など対象と操作を伝える。行内に同じボタンが並ぶ場合は、対象の名称も読み上げ名に含める。
- 「前へ」だけでなく「前の月」など移動単位を伝える。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`chevron-left`](?path=/docs/icons-chevron-left--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`calendar-chevron-left`](?path=/docs/icons-calendar-chevron-left--docs)：予定を対象にする場合。
- [`chevron-right`](?path=/docs/icons-chevron-right--docs)：次の項目・期間・ページへの移動を表す。
- [`undo`](?path=/docs/icons-undo--docs)：適用済み操作の取り消し。
- [`panel-close-left`](?path=/docs/icons-panel-close-left--docs)：左側の補助パネルを閉じる操作を表す。
