# clock

ファイル：`clock.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`time`、`duration`、`時計`、`時刻`、`時間`

時刻・所要時間を表す。時計の図柄だけで通知やカウントダウンを意味させない。

## 使用場面

- 「開始時刻を設定」：操作対象と実行結果が分かる場所で使用する。
- 「所要時間を表示」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 日時・時間帯・単位を文言で補う。期限超過などの状態は時刻表示とは別に示す。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 通知の有効状態、操作履歴、処理中のアニメーション。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「開始時刻を設定」など、図形名ではなく操作目的が分かる名前を付ける。
- 「開始14時」「所要時間30分」など値の意味と単位を含める。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`clock-off`](?path=/docs/icons-clock-off--docs)：時刻指定や時間計測を使用しない状態。時刻未入力・時間切れ・通知停止とは区別する。
- [`calendar-clock`](?path=/docs/icons-calendar-clock--docs)：予定を対象とすることを図柄でも示す場合。
- [`task-clock`](?path=/docs/icons-task-clock--docs)：タスクを対象とすることを図柄でも示す場合。
- [`bell`](?path=/docs/icons-bell--docs)：通知・リマインダー全般。音や特定の通知手段に限定しない。
- [`history`](?path=/docs/icons-history--docs)：過去の変更の閲覧。復元操作そのものとは区別する。
- [`calendar`](?path=/docs/icons-calendar--docs)：日付・予定を表す。
