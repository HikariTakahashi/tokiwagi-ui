# login

ファイル：`login.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`sign in`、`log in`、`ログイン`、`サインイン`

アカウントでサービスへログインする操作を表す。

## 使用場面

- 「ログイン」：操作対象と実行結果が分かる場所で使用する。
- 「別のアカウントでログイン」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 認証前・認証中・失敗を区別し、認証完了後は次の画面や状態を示す。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- ユーザー追加、アクセス制限の説明、ログアウト。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「ログイン」など、図形名ではなく操作目的が分かる名前を付ける。
- ログイン方法やサービス名が複数ある場合は操作名に含める。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`login-off`](?path=/docs/icons-login-off--docs)：ログイン機能の停止・利用制限。未ログインの通常状態には使わない。
- [`logout`](?path=/docs/icons-logout--docs)：現在のアカウントのセッションからログアウトする操作を表す。
- [`lock`](?path=/docs/icons-lock--docs)：ロック・アクセス制限。表示を隠すだけの操作とは区別する。
- [`link`](?path=/docs/icons-link--docs)：関連付けやリンク先への移動。共有権限とは区別する。
