# task-bookmark

ファイル：`task-bookmark.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`todo`、`checklist`、`タスク`、`作業`、`やること`、`read later`、`saved item`、`ブックマーク`、`しおり`、`後で読む`

タスクを対象とする図柄。後から見返すために対象を保存・登録することを表す。

## 使用場面

- 「タスク：あとで見るに追加」：後から対象を見返せるように登録する。固定表示とは分ける。
- タスクとほかの対象が混在し、対象を図柄でも区別したい場所で使用する。タスク詳細の中など対象が明確な場所では、基本形の [`bookmark`](?path=/docs/icons-bookmark--docs) を優先する。

## 状態の表し方

- 操作・状態の適用範囲を示す。1件のタスクなのか、選択した複数件・一覧全体なのかをラベルや周辺文言で明示する。
- 登録済みと未登録を文言や選択状態で示す。一覧への入口は登録状態を示さない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 表示順を固定する操作、他者への賛同、ファイルの保存。
- 操作できない状態表示を、押せるボタンのように見せること。
- タスクに限定されないアプリ全体の操作や、別の種類の対象への操作。

## 表示とアクセシビリティ

- 「タスク：あとで見るに追加」など対象と操作を伝える。行内に同じボタンが並ぶ場合は、対象の名称も読み上げ名に含める。
- 切り替えには「あとで見る」の固定ラベルと選択状態を伝える。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`bookmark`](?path=/docs/icons-bookmark--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`calendar-bookmark`](?path=/docs/icons-calendar-bookmark--docs)：予定を対象にする場合。
- [`pin`](?path=/docs/icons-pin--docs)：一覧などの所定の位置への固定。
- [`like`](?path=/docs/icons-like--docs)：好意・賛同、またはお気に入り登録。
- [`save`](?path=/docs/icons-save--docs)：アプリ内の変更を保存する。
