# paperclip-off

ファイル：`paperclip-off.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`attachment`、`attach`、`クリップ`、`添付`、`添付ファイル`、`off`、`オフ`、`斜線`、`disabled`、`利用不可`

`paperclip`に斜線を付けた図柄。添付機能の停止・利用制限。添付ゼロやファイル削除済みとは区別する。

## 使用場面

- 状態の表示：添付機能の停止・利用制限。添付ゼロやファイル削除済みとは区別する。
- 状態を変更する操作に添える場合は「解除する」「再開する」など実際の結果をラベルで伝える。状態表示と次の操作を同じ場所で混同させない。

## 状態の表し方

- 添付機能の停止・利用制限。添付ゼロやファイル削除済みとは区別する。
- 通常の入口・操作は [`paperclip`](?path=/docs/icons-paperclip--docs) を使う。斜線を、処理成功・処理失敗・件数ゼロの共通記号にしない。
- `-off`は図柄の状態名であり、ボタンの disabled 属性や操作可否を自動的に決めない。状態を戻せる場合は、その操作を可能にする。

## 使用しない場面

- クリップボードへのコピー、URLだけの関連付け、データのインポート。
- 理由を示さず、すべての操作不可ボタンを斜線付きに置き換えること。

## 表示とアクセシビリティ

- 「paperclip-off」や「斜線付き」ではなく、停止・解除・制限の対象と状態をテキストで伝える。
- 切り替えを操作できる場合は実際の操作名と状態を伝える。利用制限の場合は、何が制限されているかと必要な理由を添える。
- 添付ファイルの名前と操作を伝え、制限がある場合は形式や容量を案内する。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`paperclip`](?path=/docs/icons-paperclip--docs)：通常の図柄。停止・制限を示さない入口や操作に使う。
- [`upload`](?path=/docs/icons-upload--docs)：外部からファイル・データを読み込む。
- [`link`](?path=/docs/icons-link--docs)：関連付けやリンク先への移動。共有権限とは区別する。
- [`image`](?path=/docs/icons-image--docs)：画像の挿入・表示。
