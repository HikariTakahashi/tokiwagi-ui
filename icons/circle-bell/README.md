# circle-bell

ファイル：`circle-bell.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`round`、`ring`、`円`、`丸`、`円枠`、`notification`、`reminder`、`alarm`、`ベル`、`鈴`、`通知`、`リマインダー`

円枠の図柄。ユーザーに情報や予定を知らせる通知・リマインダーを表す。画面・音・メール・光など通知手段を限定しない。 枠の形そのものは重要度・操作可否・選択状態を意味しない。

## 使用場面

- 「通知一覧を開く」：操作対象と実行結果が分かる場所で使用する。
- 「リマインダーを設定」：同じ部品では意味を固定し、別の操作を兼ねさせない。
- 同じ領域で円枠の表現を採用する場合に使用する。枠付きアイコンを使うだけでボタンとしての役割を与えない。

## 状態の表し方

- 通知オン、未設定、停止、未読ゼロを区別する。通知日時や「通知オフ」などの文言を添え、未読ゼロはバッジなしで示す。
- 通知設定の件数と未読件数を混在させない。権限の未許可・配信失敗は原因を文言で示し、通知の到達を図柄だけで保証しない。

- 入口の bell は通知オンを保証しない。通知日時・有効状態・未読件数は別々に表示する。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。
- 成功・注意・失敗などの役割は、内容を説明する文言とセマンティックカラーで示す。枠の形だけで役割を変えない。

## 使用しない場面

- 通知設定そのものの削除。削除操作は `delete` で表す。

- 音量だけの調整、締切時刻だけの表示、エラーや重要度の代用。
- 操作できない状態表示を、押せるボタンのように見せること。
- 枠の違いだけで、重要度・操作内容・選択状態を使い分けること。

## 表示とアクセシビリティ

- アイコンだけの操作には「通知一覧を開く」など、図形名ではなく操作目的が分かる名前を付ける。
- 未読バッジには「未読3件」など数える対象を含む名前を付ける。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

- [`mail`](?path=/docs/icons-mail--docs)：メール・メッセージという手段や内容を表す。
- [`setting`](?path=/docs/icons-setting--docs)：設定への入口。
