# menu

ファイル：`menu.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`hamburger`、`navigation`、`メニュー`、`三本線`、`ナビゲーション`

アプリ全体の主メニューやナビゲーションを開く操作を表す。

## 使用場面

- 「メニューを開く」：操作対象と実行結果が分かる場所で使用する。
- 「ナビゲーションを表示」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- メニューの開閉状態を伝える。項目ごとの補助操作と区別する。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- ドラッグハンドル、単一項目のその他の操作、文章の整列。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「メニューを開く」など、図形名ではなく操作目的が分かる名前を付ける。
- 展開状態と操作対象のメニューを伝え、閉じた後のフォーカスを保つ。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`menu-off`](?path=/docs/icons-menu-off--docs)：主メニューが利用できない状態。閉じている通常状態には使わない。
- [`ellipsis`](?path=/docs/icons-ellipsis--docs)：横三点の補助操作メニュー。
- [`panel-left`](?path=/docs/icons-panel-left--docs)：左側の補助パネルを表示する操作、または配置を表す。
- [`close`](?path=/docs/icons-close--docs)：表示を閉じる・操作をキャンセルする。
