# grip-vertical

ファイル：`grip-vertical.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`drag`、`handle`、`vertical grip`、`ドラッグ`、`つまみ`、`縦グリップ`

縦長のつまみで、対象をつかんで移動・並べ替えできることを表す。

## 使用場面

- 「タスクの順序を変更」：操作対象と実行結果が分かる場所で使用する。
- 「項目をドラッグして移動」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 移動中の項目と配置先を示す。図柄が縦長でも移動方向を縦だけに限定しない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- その他の操作メニュー、区切り線、上下へのスクロール。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「タスクの順序を変更」など、図形名ではなく操作目的が分かる名前を付ける。
- 移動対象名と移動後の位置を伝え、キーボードによる代替操作を用意する。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`grip-vertical-off`](?path=/docs/icons-grip-vertical-off--docs)：ドラッグによる移動が制限されている状態。配置完了を意味しない。
- [`grip-horizontal`](?path=/docs/icons-grip-horizontal--docs)：横長のドラッグハンドル。
- [`sort`](?path=/docs/icons-sort--docs)：表示順の変更。
- [`ellipsis-vertical`](?path=/docs/icons-ellipsis-vertical--docs)：縦三点の補助操作メニュー。
