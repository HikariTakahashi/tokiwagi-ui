# sort-number-down

ファイル：`sort-number-down.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`sort ascending`、`numeric`、`並べ替え`、`ソート`、`数値`、`昇順`

数値を昇順（小さい値から大きい値）に並べる操作・状態を表す。

## 使用場面

- 「件数の少ない順に並べ替え」：操作対象と実行結果が分かる場所で使用する。
- 「所要時間の短い順に表示」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 対象の数値と単位を示す。文字列としての順序と数値の大小順を混同しない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 文字の辞書順、下方向への移動、数量を減らす操作。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「件数の少ない順に並べ替え」など、図形名ではなく操作目的が分かる名前を付ける。
- 「所要時間：短い順」のように意味の分かる方向を伝える。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`sort-number-down-off`](?path=/docs/icons-sort-number-down-off--docs)：数値昇順の並べ替えが未適用・利用不可の状態。どちらかを文言で特定する。
- [`sort-number-up`](?path=/docs/icons-sort-number-up--docs)：数値を降順（大きい値から小さい値）に並べる操作・状態を表す。
- [`sort-alphabet-down`](?path=/docs/icons-sort-alphabet-down--docs)：文字列を昇順（A → Z）に並べる操作・状態を表す。
- [`sort`](?path=/docs/icons-sort--docs)：表示順の変更。
