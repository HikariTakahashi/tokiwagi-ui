# ellipsis-vertical-off

ファイル：`ellipsis-vertical-off.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`more`、`overflow`、`vertical dots`、`縦三点`、`その他`、`off`、`オフ`、`斜線`、`disabled`、`利用不可`

`ellipsis-vertical`に斜線を付けた図柄。補助操作メニューが利用できない状態。閉じた状態とは区別する。

## 使用場面

- 状態の表示：補助操作メニューが利用できない状態。閉じた状態とは区別する。
- 状態を変更する操作に添える場合は「解除する」「再開する」など実際の結果をラベルで伝える。状態表示と次の操作を同じ場所で混同させない。

## 状態の表し方

- 補助操作メニューが利用できない状態。閉じた状態とは区別する。
- 通常の入口・操作は [`ellipsis-vertical`](?path=/docs/icons-ellipsis-vertical--docs) を使う。斜線を、処理成功・処理失敗・件数ゼロの共通記号にしない。
- `-off`は図柄の状態名であり、ボタンの disabled 属性や操作可否を自動的に決めない。状態を戻せる場合は、その操作を可能にする。

## 使用しない場面

- 縦方向への移動、ドラッグハンドル、読み込み中。
- 理由を示さず、すべての操作不可ボタンを斜線付きに置き換えること。

## 表示とアクセシビリティ

- 「ellipsis-vertical-off」や「斜線付き」ではなく、停止・解除・制限の対象と状態をテキストで伝える。
- 切り替えを操作できる場合は実際の操作名と状態を伝える。利用制限の場合は、何が制限されているかと必要な理由を添える。
- メニューを開く対象名を伝え、キーボードで開閉と項目選択ができるようにする。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`ellipsis-vertical`](?path=/docs/icons-ellipsis-vertical--docs)：通常の図柄。停止・制限を示さない入口や操作に使う。
- [`ellipsis`](?path=/docs/icons-ellipsis--docs)：横三点の補助操作メニュー。
- [`menu`](?path=/docs/icons-menu--docs)：アプリ全体の主メニューを開く。
- [`grip-vertical`](?path=/docs/icons-grip-vertical--docs)：縦長のドラッグハンドル。
