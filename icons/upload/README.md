# upload

ファイル：`upload.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`import`、`アップロード`、`読み込み`

端末や外部からファイル・データを読み込む操作を表す。

## 使用場面

- 「ファイルを読み込む」：操作対象と実行結果が分かる場所で使用する。
- 「予定データをインポート」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- ファイル選択・転送中・取り込み完了・失敗を区別する。既存データへの追加・上書きを明示する。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- ダウンロード、共有設定、保存操作、単なる上方向への移動。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「ファイルを読み込む」など、図形名ではなく操作目的が分かる名前を付ける。
- 受け付ける形式と対象を伝え、ドラッグ＆ドロップ以外の選択方法も提供する。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`upload-off`](?path=/docs/icons-upload-off--docs)：読み込み・アップロード機能の停止・利用制限。読み込み失敗や未選択とは区別する。
- [`calendar-upload`](?path=/docs/icons-calendar-upload--docs)：予定を対象とすることを図柄でも示す場合。
- [`task-upload`](?path=/docs/icons-task-upload--docs)：タスクを対象とすることを図柄でも示す場合。
- [`download`](?path=/docs/icons-download--docs)：ファイル・データを書き出す。
- [`paperclip`](?path=/docs/icons-paperclip--docs)：対象への添付。クリップボードへのコピーには使わない。
- [`save`](?path=/docs/icons-save--docs)：アプリ内の変更を保存する。
