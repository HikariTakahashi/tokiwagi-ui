# search-information

ファイル：`search-information.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`find`、`magnifier`、`search info`、`検索`、`虫眼鏡`、`検索の補足`、`検索の注意`

検索に関する補足・注意を案内する。

## 使用場面

- 「検索条件の説明を表示」：操作対象と実行結果が分かる場所で使用する。
- 「検索の注意事項を表示」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 説明・注意・失敗の内容を文言で特定する。感嘆符だけで検索失敗と決めない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 検索結果ゼロの単独表現、検索実行、検索条件の確定。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「検索条件の説明を表示」など、図形名ではなく操作目的が分かる名前を付ける。
- 「検索対象の説明」など案内の内容を読み上げ名に含める。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`search-information-off`](?path=/docs/icons-search-information-off--docs)：検索の補足案内を停止・非表示にした状態。問題解消を意味しない。
- [`search`](?path=/docs/icons-search--docs)：対象を探す検索。
- [`information`](?path=/docs/icons-information--docs)：補足や注意を文言とともに示す。
- [`help`](?path=/docs/icons-help--docs)：使い方の説明への入口。
