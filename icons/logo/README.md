# logo

ファイル：[logo.svg](./logo.svg) · 状態：ロゴ使用ルール案（SVG原本作成済み・Storybook掲載済み・アプリ画面への適用前）

## 概要

別名：`tokiwagi`、`tokiwagi-ui`、`brand`、`ロゴ`、`ブランド`、`ときわぎ`

Tokiwagi UIを識別するためのブランドロゴ。3つの同心円と、ブルー・ピンク・グリーンの3つの丸で構成する。図形の原本は同じディレクトリの `logo.svg` とする。

**意味づけの案**：途切れずに続く輪に、[TokiWa Calendarのフィロソフィー](../../../PHILOSOPHY.md) にある「共に続く『わ』」を重ねる。色の異なる丸は、一つひとつの部品や工夫を表す。それらを共通のルールで結び、日々の使いやすさを次の体験へつなげていく姿勢を表現する。これはフィロソフィーに基づく解釈案であり、図形の作成意図として確定した説明ではない。

デザインシステムのキャッチコピーは「変わる毎日に、変わらない使いやすさを。」とする。

## 使用場面

- **LPのヘッダー・フッター**：デザインシステムの名称「Tokiwagi UI」と併記し、サイトの識別に使う。
- **Storybookや利用ガイド**：Tokiwagi UIの資料であることを示す位置に置く。
- **紹介資料の表紙・クレジット**：デザインシステム名と合わせて、提供元や参照先を示す。
- **ホームへの入口**：ヘッダーのブランド領域をリンクにする場合、ロゴと名称を一つのリンクとして扱う。リンク先はTokiwagi UIのホームとする。

初めて見る人が名称を確認できるよう、基本は名称との併記とする。ロゴ単体での使用は、同じ画面内でTokiwagi UIの名称を確認できる場所に限る。

## 状態の表し方

- ロゴはブランドの識別を担い、図形と配色を一定に保つ。
- ホームへのリンクとして使う場合、ホバー・押下・キーボードフォーカスは、親のリンク領域の背景・輪郭・名称の下線などで示す。
- 読み込み中、成功、警告、エラー、選択中などの状態は、専用の部品や文言で伝える。
- 状態に合わせて3つの丸の色を切り替えたり、輪を増減したり、丸をバッジとして点滅させたりしない。

## 使用しない場面

- 予定・タスク・通知・設定など、個別の機能や操作を表す場所。
- 未読件数、進捗、重要度、成功・警告・エラーを示す状態表示。
- チェックボックス、ラジオボタン、ローディング表示の代用。
- Tokiwagi UIとの関係を示す説明がない、他のサービスやアプリの識別表示。
- 模様や背景としての反復配置、文字や他の図形と重ねて識別しづらくする装飾。

## 表示とアクセシビリティ

**形状**

- `viewBox="0 0 32 32"` と1:1の縦横比を保持する。
- 原本の3つの輪、3つの丸、その位置・大きさ・重なりを保持する。輪の線幅は原本の `2` を基準に、図形全体と一緒に拡大・縮小する。
- 縦横別々の拡大・縮小、回転、反転、トリミング、線幅だけの変更をしない。影、グラデーション、追加の枠などをロゴ自体に加えない。

**配色**

原本に対応する色は次のとおり。色の定義元は [colors.css](../../tokens/colors.css) と [neutrals.css](../../tokens/neutrals.css) とし、このREADMEにHEX値を複製しない。

| 構成要素 | カラートークン |
| --- | --- |
| 3つの輪 | `--tkw-color-neutral-1000` |
| 内側の輪に重なる丸 | `--tkw-color-primary-blue` |
| 中間の輪に重なる丸 | `--tkw-color-primary-rose` |
| 外側の輪に重なる丸 | `--tkw-color-primary-green` |

- 3つの丸には基本色を使い、ホバー色・押下色・状態色へ切り替えない。
- 共通アイコンの表示変換で輪が `currentColor` になる場合も、表示側で輪の色を上記トークンに固定する。親の文字色やリンクの状態色に合わせて変化させない。
- ロゴの3色は固定配色とする。デザインシステム全体の7色のプライマリーは対等に扱う。
- 単色版・反転版・ダーク背景向けの別配色は、この原本には含めない。

**サイズ・余白・背景**

- 最小表示サイズは32×32 CSS pxとする。拡大時も正方形を保ち、32px未満へ縮小しない。
- 32px表示時は、SVGの表示領域の外側に上下左右8px以上の余白を確保する。拡大時は表示幅の1/4以上の余白を確保する。
- 名称を併記する場合も同じ余白を保ち、縦方向の中心をそろえる。名称はSVGへ書き込まず、テキストで表示する。
- 背景はライトモードの `--tkw-color-neutral-0` または `--tkw-color-neutral-50` を基本とする。写真・模様・濃色の背景上では、ロゴ領域にこの背景と余白を確保する。
- リンクの操作領域は余白を含む親要素で確保し、フォーカスの輪郭が切れないようにする。

**読み上げ・操作**

- 名称を併記する場合、画像の `alt` は空にする。インラインSVGでは `aria-hidden="true"` と `focusable="false"` を指定し、名称を二重に読み上げさせない。
- ロゴ単体でブランドを伝える画像には `alt="Tokiwagi UI"` を付ける。インラインSVGでは `role="img"` と `aria-label="Tokiwagi UI"` を指定する。
- ロゴ単体のホームリンクには、親のリンクに `aria-label="Tokiwagi UI ホーム"` を付け、ロゴは装飾として扱う。
- ロゴと名称を併記するホームリンクも、リンクの目的が「Tokiwagi UI ホーム」と分かる名前を付ける。
- 輪や丸を個別の操作対象にせず、キーボードで操作できる親のリンクを使う。静的なブランド表示にはフォーカスを与えない。
- ブランド名や操作目的を3色だけに依存させず、テキストまたは読み上げ名で伝える。

## 関連アイコンと使い分け

- [calendar](../calendar/README.md)：カレンダー・日付・予定を表す。Tokiwagi UIのブランド識別には `logo` を使う。
- [task](../task/README.md)：実行する作業を表す。ロゴの丸や輪でタスクの状態を表さない。
- [bell](../bell/README.md)：通知・リマインダーを表す。通知のバッジをロゴに付けず、通知機能の入口に表示する。

`logo` はブランド資産として扱う。Storybookの「ロゴ/使用ルール」で32・64・128pxの見本、名称との併記、原本SVGのダウンロードを確認できる。汎用アイコンの一覧とTIconの公開名には含めず、固定配色と最小32pxのルールに従って原本を使用する。アプリ画面への適用は未実施。
