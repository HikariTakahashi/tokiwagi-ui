# calendar-clock

ファイル：`calendar-clock.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`date`、`schedule`、`event`、`カレンダー`、`日付`、`予定`、`time`、`duration`、`時計`、`時刻`、`時間`

予定を対象とする図柄。時刻・所要時間を表す。時計の図柄だけで通知やカウントダウンを意味させない。

## 使用場面

- 「予定：時刻を設定」：開始時刻や所要時間を表示・設定する。通知時刻は通知の文脈を添える。
- 予定とほかの対象が混在し、対象を図柄でも区別したい場所で使用する。予定詳細の中など対象が明確な場所では、基本形の [`clock`](?path=/docs/icons-clock--docs) を優先する。

## 状態の表し方

- 操作・状態の適用範囲を示す。1件の予定なのか、選択した複数件・一覧全体なのかをラベルや周辺文言で明示する。
- 日時・時間帯・単位を文言で補う。期限超過などの状態は時刻表示とは別に示す。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 通知の有効状態、操作履歴、処理中のアニメーション。
- 操作できない状態表示を、押せるボタンのように見せること。
- 予定に限定されないアプリ全体の操作や、別の種類の対象への操作。

## 表示とアクセシビリティ

- 「予定：時刻を設定」など対象と操作を伝える。行内に同じボタンが並ぶ場合は、対象の名称も読み上げ名に含める。
- 「開始14時」「所要時間30分」など値の意味と単位を含める。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`clock`](?path=/docs/icons-clock--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`task-clock`](?path=/docs/icons-task-clock--docs)：タスクを対象にする場合。
- [`bell`](?path=/docs/icons-bell--docs)：通知・リマインダー全般。音や特定の通知手段に限定しない。
- [`history`](?path=/docs/icons-history--docs)：過去の変更の閲覧。復元操作そのものとは区別する。
- [`calendar`](?path=/docs/icons-calendar--docs)：日付・予定を表す。
