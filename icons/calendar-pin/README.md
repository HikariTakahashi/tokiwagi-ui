# calendar-pin

ファイル：`calendar-pin.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`date`、`schedule`、`event`、`カレンダー`、`日付`、`予定`、`pushpin`、`pinned`、`ピン`、`画鋲`、`固定`

予定を対象とする図柄。対象を目立つ位置や所定の位置に固定する操作・状態を表す。

## 使用場面

- 「予定：上部に固定」：対象を一覧の所定の位置に固定する。固定が自分だけか共同利用者全体かを示す。
- 予定とほかの対象が混在し、対象を図柄でも区別したい場所で使用する。予定詳細の中など対象が明確な場所では、基本形の [`pin`](?path=/docs/icons-pin--docs) を優先する。

## 状態の表し方

- 操作・状態の適用範囲を示す。1件の予定なのか、選択した複数件・一覧全体なのかをラベルや周辺文言で明示する。
- 固定先と適用範囲を示す。全員に共有される固定か自分だけの固定かを明確にする。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- あとで見るための保存、好意の表明、位置情報。
- 操作できない状態表示を、押せるボタンのように見せること。
- 予定に限定されないアプリ全体の操作や、別の種類の対象への操作。

## 表示とアクセシビリティ

- 「予定：上部に固定」など対象と操作を伝える。行内に同じボタンが並ぶ場合は、対象の名称も読み上げ名に含める。
- 固定の切り替えには対象名と選択状態を付ける。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`pin`](?path=/docs/icons-pin--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`task-pin`](?path=/docs/icons-task-pin--docs)：タスクを対象にする場合。
- [`bookmark`](?path=/docs/icons-bookmark--docs)：後で見返すための登録。
- [`like`](?path=/docs/icons-like--docs)：好意・賛同、またはお気に入り登録。
- [`sort`](?path=/docs/icons-sort--docs)：表示順の変更。
