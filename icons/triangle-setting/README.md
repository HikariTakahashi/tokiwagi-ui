# triangle-setting

ファイル：`triangle-setting.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`triangular`、`三角`、`三角形`、`三角枠`、`settings`、`gear`、`cog`、`preferences`、`設定`、`歯車`

三角枠の図柄。設定画面や設定項目への入口を表す。 枠の形そのものは重要度・操作可否・選択状態を意味しない。

## 使用場面

- 「設定を開く」：操作対象と実行結果が分かる場所で使用する。
- 「表示設定を変更」：同じ部品では意味を固定し、別の操作を兼ねさせない。
- 同じ領域で三角枠の表現を採用する場合に使用する。枠付きアイコンを使うだけでボタンとしての役割を与えない。

## 状態の表し方

- 設定画面の開閉と個々の設定値を区別する。歯車の図柄だけで設定済みを示さない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。
- 成功・注意・失敗などの役割は、内容を説明する文言とセマンティックカラーで示す。枠の形だけで役割を変えない。

## 使用しない場面

- 任意の内容編集、管理ツール全般、保存操作。
- 操作できない状態表示を、押せるボタンのように見せること。
- 枠の違いだけで、重要度・操作内容・選択状態を使い分けること。

## 表示とアクセシビリティ

- アイコンだけの操作には「設定を開く」など、図形名ではなく操作目的が分かる名前を付ける。
- 「カレンダーの設定」など設定対象を明確にする。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`setting`](?path=/docs/icons-setting--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`edit`](?path=/docs/icons-edit--docs)：既存の内容を変更する。
- [`tool`](?path=/docs/icons-tool--docs)：管理・保守などのツールへの入口。
- [`bell`](?path=/docs/icons-bell--docs)：通知・リマインダー全般。音や特定の通知手段に限定しない。
- [`circle-setting`](?path=/docs/icons-circle-setting--docs)：円枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
- [`square-setting`](?path=/docs/icons-square-setting--docs)：四角枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
