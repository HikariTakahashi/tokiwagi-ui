# task-paperclip

ファイル：`task-paperclip.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`todo`、`checklist`、`タスク`、`作業`、`やること`、`attachment`、`attach`、`クリップ`、`添付`、`添付ファイル`

タスクを対象とする図柄。既存の対象にファイルを添付する操作、または添付がある状態を表す。

## 使用場面

- 「タスク：ファイルを添付」：対象に資料を添付する。ファイル名と件数を表示する。
- タスクとほかの対象が混在し、対象を図柄でも区別したい場所で使用する。タスク詳細の中など対象が明確な場所では、基本形の [`paperclip`](?path=/docs/icons-paperclip--docs) を優先する。

## 状態の表し方

- 操作・状態の適用範囲を示す。1件のタスクなのか、選択した複数件・一覧全体なのかをラベルや周辺文言で明示する。
- 追加操作と添付済み表示を区別し、ファイル名・件数・転送結果を併記する。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- クリップボードへのコピー、URLだけの関連付け、データのインポート。
- 操作できない状態表示を、押せるボタンのように見せること。
- タスクに限定されないアプリ全体の操作や、別の種類の対象への操作。

## 表示とアクセシビリティ

- 「タスク：ファイルを添付」など対象と操作を伝える。行内に同じボタンが並ぶ場合は、対象の名称も読み上げ名に含める。
- 添付ファイルの名前と操作を伝え、制限がある場合は形式や容量を案内する。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`paperclip`](?path=/docs/icons-paperclip--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`calendar-paperclip`](?path=/docs/icons-calendar-paperclip--docs)：予定を対象にする場合。
- [`upload`](?path=/docs/icons-upload--docs)：外部からファイル・データを読み込む。
- [`link`](?path=/docs/icons-link--docs)：関連付けやリンク先への移動。共有権限とは区別する。
- [`image`](?path=/docs/icons-image--docs)：画像の挿入・表示。
