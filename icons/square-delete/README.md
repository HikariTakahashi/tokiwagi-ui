# square-delete

ファイル：`square-delete.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`box`、`rectangle`、`四角`、`四角枠`、`正方形`、`trash`、`trashcan`、`bin`、`削除`、`ゴミ箱`

四角枠の図柄。保存済みの対象データを削除することを表す。 枠の形そのものは重要度・操作可否・選択状態を意味しない。

## 使用場面

- 「予定を削除」：操作対象と実行結果が分かる場所で使用する。
- 「添付ファイルを削除」：同じ部品では意味を固定し、別の操作を兼ねさせない。
- 同じ領域で四角枠の表現を採用する場合に使用する。枠付きアイコンを使うだけでボタンとしての役割を与えない。

## 状態の表し方

- 削除対象と影響範囲を明示する。復元できる場合は復元方法を、できない場合は確定前にその結果を示す。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。
- 成功・注意・失敗などの役割は、内容を説明する文言とセマンティックカラーで示す。枠の形だけで役割を変えない。

## 使用しない場面

- 画面を閉じる、選択を解除する、一覧から関連付けだけを外す。
- 操作できない状態表示を、押せるボタンのように見せること。
- 枠の違いだけで、重要度・操作内容・選択状態を使い分けること。

## 表示とアクセシビリティ

- アイコンだけの操作には「予定を削除」など、図形名ではなく操作目的が分かる名前を付ける。
- アイコンだけの操作には削除対象名を含める。削除後のフォーカス先を残る項目などに移す。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`delete`](?path=/docs/icons-delete--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`close`](?path=/docs/icons-close--docs)：表示を閉じる・操作をキャンセルする。
- [`minus`](?path=/docs/icons-minus--docs)：集合からの除外や数量の減少。元データの削除とは区別する。
- [`undo`](?path=/docs/icons-undo--docs)：適用済み操作の取り消し。
- [`circle-delete`](?path=/docs/icons-circle-delete--docs)：円枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
- [`triangle-delete`](?path=/docs/icons-triangle-delete--docs)：三角枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
