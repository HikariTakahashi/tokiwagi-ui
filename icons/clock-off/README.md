# clock-off

ファイル：`clock-off.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`time`、`duration`、`時計`、`時刻`、`時間`、`off`、`オフ`、`斜線`、`inactive`、`時刻指定なし`

`clock`に斜線を付けた図柄。時刻指定や時間計測を使用しない状態。時刻未入力・時間切れ・通知停止とは区別する。

## 使用場面

- 状態の表示：時刻指定や時間計測を使用しない状態。時刻未入力・時間切れ・通知停止とは区別する。
- 状態を変更する操作に添える場合は「解除する」「再開する」など実際の結果をラベルで伝える。状態表示と次の操作を同じ場所で混同させない。

## 状態の表し方

- 時刻指定や時間計測を使用しない状態。時刻未入力・時間切れ・通知停止とは区別する。
- 通常の入口・操作は [`clock`](?path=/docs/icons-clock--docs) を使う。斜線を、処理成功・処理失敗・件数ゼロの共通記号にしない。
- `-off`は図柄の状態名であり、ボタンの disabled 属性や操作可否を自動的に決めない。状態を戻せる場合は、その操作を可能にする。

## 使用しない場面

- 通知の有効状態、操作履歴、処理中のアニメーション。
- 理由を示さず、すべての操作不可ボタンを斜線付きに置き換えること。

## 表示とアクセシビリティ

- 「clock-off」や「斜線付き」ではなく、停止・解除・制限の対象と状態をテキストで伝える。
- 切り替えを操作できる場合は実際の操作名と状態を伝える。利用制限の場合は、何が制限されているかと必要な理由を添える。
- 「開始14時」「所要時間30分」など値の意味と単位を含める。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`clock`](?path=/docs/icons-clock--docs)：通常の図柄。停止・制限を示さない入口や操作に使う。
- [`bell`](?path=/docs/icons-bell--docs)：通知・リマインダー全般。音や特定の通知手段に限定しない。
- [`history`](?path=/docs/icons-history--docs)：過去の変更の閲覧。復元操作そのものとは区別する。
- [`calendar`](?path=/docs/icons-calendar--docs)：日付・予定を表す。
