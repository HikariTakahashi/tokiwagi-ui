# task-plus

ファイル：`task-plus.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`todo`、`checklist`、`タスク`、`作業`、`やること`、`add`、`create`、`increase`、`プラス`、`追加`、`作成`、`増やす`

タスクを対象とする図柄。新しい項目を追加する、または数量を増やす操作を表す。

## 使用場面

- 「タスク：追加する」：新しい対象を作成する。作成先を示し、複製とは区別する。
- タスクとほかの対象が混在し、対象を図柄でも区別したい場所で使用する。タスク詳細の中など対象が明確な場所では、基本形の [`plus`](?path=/docs/icons-plus--docs) を優先する。

## 状態の表し方

- 操作・状態の適用範囲を示す。1件のタスクなのか、選択した複数件・一覧全体なのかをラベルや周辺文言で明示する。
- 追加する対象と作成先、増分と上限を明確にする。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 既存項目の編集、内容の複製、表示倍率の変更。
- 操作できない状態表示を、押せるボタンのように見せること。
- タスクに限定されないアプリ全体の操作や、別の種類の対象への操作。

## 表示とアクセシビリティ

- 「タスク：追加する」など対象と操作を伝える。行内に同じボタンが並ぶ場合は、対象の名称も読み上げ名に含める。
- 「通知を追加」「人数を1増やす」など操作結果を名前に含める。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`plus`](?path=/docs/icons-plus--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`calendar-plus`](?path=/docs/icons-calendar-plus--docs)：予定を対象にする場合。
- [`minus`](?path=/docs/icons-minus--docs)：集合からの除外や数量の減少。元データの削除とは区別する。
- [`copy`](?path=/docs/icons-copy--docs)：元の内容を残して複製する。
- [`zoom-in`](?path=/docs/icons-zoom-in--docs)：内容の表示倍率を上げる拡大操作を表す。
