# triangle-filter

ファイル：`triangle-filter.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`triangular`、`三角`、`三角形`、`三角枠`、`funnel`、`絞り込み`、`フィルター`、`漏斗`

三角枠の図柄。表示対象を条件で絞り込む操作・適用状態を表す。 枠の形そのものは重要度・操作可否・選択状態を意味しない。

## 使用場面

- 「絞り込み条件を開く」：操作対象と実行結果が分かる場所で使用する。
- 「担当者で絞り込む」：同じ部品では意味を固定し、別の操作を兼ねさせない。
- 同じ領域で三角枠の表現を採用する場合に使用する。枠付きアイコンを使うだけでボタンとしての役割を与えない。

## 状態の表し方

- 適用中の条件や条件数を併記する。結果ゼロ、条件なし、機能停止を区別する。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。
- 成功・注意・失敗などの役割は、内容を説明する文言とセマンティックカラーで示す。枠の形だけで役割を変えない。

## 使用しない場面

- 並べ替え、文字検索そのもの、データ削除。
- 操作できない状態表示を、押せるボタンのように見せること。
- 枠の違いだけで、重要度・操作内容・選択状態を使い分けること。

## 表示とアクセシビリティ

- アイコンだけの操作には「絞り込み条件を開く」など、図形名ではなく操作目的が分かる名前を付ける。
- 現在の条件と解除方法をテキストでも確認できるようにする。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`filter`](?path=/docs/icons-filter--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`search`](?path=/docs/icons-search--docs)：対象を探す検索。
- [`sort`](?path=/docs/icons-sort--docs)：表示順の変更。
- [`close`](?path=/docs/icons-close--docs)：表示を閉じる・操作をキャンセルする。
- [`circle-filter`](?path=/docs/icons-circle-filter--docs)：円枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
- [`square-filter`](?path=/docs/icons-square-filter--docs)：四角枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
