# calendar-copy

ファイル：`calendar-copy.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`date`、`schedule`、`event`、`カレンダー`、`日付`、`予定`、`duplicate`、`コピー`、`複製`

予定を対象とする図柄。元の内容を残したまま、データや内容を複製することを表す。

## 使用場面

- 「予定：複製する」：元を残して別の日付・場所へ複製する。クリップボードへのコピーとラベルを分ける。
- 予定とほかの対象が混在し、対象を図柄でも区別したい場所で使用する。予定詳細の中など対象が明確な場所では、基本形の [`copy`](?path=/docs/icons-copy--docs) を優先する。
- 既存フロントエンドの予定複製候補。Display.vue で並ぶクリップボードへのコピーとは、操作名と結果を区別する。

## 状態の表し方

- 操作・状態の適用範囲を示す。1件の予定なのか、選択した複数件・一覧全体なのかをラベルや周辺文言で明示する。
- 複製対象と作成先を示す。クリップボードへコピーする場合はその保存先をラベルに明記する。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 元を移動する操作、切り取り、共有、保存だけの操作。
- 操作できない状態表示を、押せるボタンのように見せること。
- 予定に限定されないアプリ全体の操作や、別の種類の対象への操作。

## 表示とアクセシビリティ

- 「予定：複製する」など対象と操作を伝える。行内に同じボタンが並ぶ場合は、対象の名称も読み上げ名に含める。
- 「予定を複製」「リンクをクリップボードにコピー」のように結果を区別する。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`copy`](?path=/docs/icons-copy--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`task-copy`](?path=/docs/icons-task-copy--docs)：タスクを対象にする場合。
- [`cut`](?path=/docs/icons-cut--docs)：元を別の場所へ移すために切り取る。
- [`share`](?path=/docs/icons-share--docs)：共有先と権限の設定。同期とは区別する。
