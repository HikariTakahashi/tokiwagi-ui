# triangle

ファイル：`triangle.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`triangular`、`三角`、`三角形`、`三角枠`

三角形の枠として記号を囲む表現に使用する。

## 使用場面

- 「三角形の記号枠を表示」：操作対象と実行結果が分かる場所で使用する。
- 「図形の種類を選択」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 三角形の枠自体に警告の意味を固定しない。警告として用いる場合は内容と重要度を文言で示す。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 再生、方向移動、文言のない警告の代用。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「三角形の記号枠を表示」など、図形名ではなく操作目的が分かる名前を付ける。
- 枠だけの装飾は読み上げず、意味を持つ場合は内容を名前に含める。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`triangle-off`](?path=/docs/icons-triangle-off--docs)：三角形の印で表す機能の停止状態。警告解消や安全を意味しない。
- [`circle`](?path=/docs/icons-circle--docs)：円形の枠や未選択の印として使用する。
- [`square`](?path=/docs/icons-square--docs)：四角形の枠や項目を囲む表現に使用する。
- [`triangle-information`](?path=/docs/icons-triangle-information--docs)：図柄の用途を個別ページで確認する。
