# square-check

ファイル：`square-check.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`box`、`rectangle`、`四角`、`四角枠`、`正方形`、`tick`、`done`、`complete`、`チェック`、`チェックマーク`、`完了`、`選択済み`

四角枠の図柄。選択済み・完了を表す。何が選択または完了したかを対象とともに示す。 枠の形そのものは重要度・操作可否・選択状態を意味しない。

## 使用場面

- 「タスクを完了にする」：操作対象と実行結果が分かる場所で使用する。
- 「選択済みの項目を示す」：同じ部品では意味を固定し、別の操作を兼ねさせない。
- 同じ領域で四角枠の表現を採用する場合に使用する。枠付きアイコンを使うだけでボタンとしての役割を与えない。
- チェックボックスの選択済み表示に使う場合は、操作部品のチェック状態と一致させる。図柄だけで入力部品を実装したことにはしない。

## 状態の表し方

- 選択・タスク完了・処理成功のどれかを文脈ごとに固定する。未保存の入力に保存成功の印を付けない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。
- 成功・注意・失敗などの役割は、内容を説明する文言とセマンティックカラーで示す。枠の形だけで役割を変えない。

## 使用しない場面

- 未選択、進行中、単に次へ進む操作、未検証の成功。
- 操作できない状態表示を、押せるボタンのように見せること。
- 枠の違いだけで、重要度・操作内容・選択状態を使い分けること。

## 表示とアクセシビリティ

- アイコンだけの操作には「タスクを完了にする」など、図形名ではなく操作目的が分かる名前を付ける。
- 選択にはチェックボックス等の状態を、完了表示には対象名と「完了」を伝える。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`check`](?path=/docs/icons-check--docs)：対象や枠のない基本形。周辺の文脈で対象が明確な場合はこちらを基本とする。
- [`circle-check`](?path=/docs/icons-circle-check--docs)：文言とともに処理成功を示す場合にも使う。
- [`close`](?path=/docs/icons-close--docs)：表示を閉じる・操作をキャンセルする。
- [`save`](?path=/docs/icons-save--docs)：アプリ内の変更を保存する。
- [`triangle-check`](?path=/docs/icons-triangle-check--docs)：三角枠の同じ記号。枠だけで別の操作・重要度を割り当てない。
