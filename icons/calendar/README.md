# calendar

ファイル：`calendar.svg` · 状態：詳細ルール案（SVG収録済み・既存画面への適用前）

## 概要

別名：`date`、`schedule`、`event`、`カレンダー`、`日付`、`予定`

カレンダー・日付・予定を表す。

## 使用場面

- 「カレンダーを開く」：操作対象と実行結果が分かる場所で使用する。
- 「日付を選択」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 今日・選択日・予定ありを区別する。カレンダーの図柄だけでは特定の日付を表さない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- タスク完了、通知設定済み、時刻のみの入力。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「カレンダーを開く」など、図形名ではなく操作目的が分かる名前を付ける。
- 選択日を年月日で伝え、色だけで今日や選択日を区別しない。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`calendar-off`](?path=/docs/icons-calendar-off--docs)：カレンダー機能の停止・非表示。予定ゼロや日付未選択を意味しない。
- [`task`](?path=/docs/icons-task--docs)：実行する作業を表し、完了状態を意味しない。
- [`clock`](?path=/docs/icons-clock--docs)：時刻・所要時間を表し、通知設定の有無を意味しない。
- [`calendar-bell`](?path=/docs/icons-calendar-bell--docs)：予定に関する通知であることを図柄でも区別する場合に使う。
