# コンポーネントプレビューのUIルール

Storybookは実コンポーネントの表示と設定変更を確認する場所です。TIcon・TBrand・TLogoは「コンポーネント」に分類し、各コンポーネントのDefaultストーリーを置きます。詳細な説明はREADME・原本側の使用ルールで保持し、Astro側への説明ページ移設は別作業です。

## CanvasとControls

- 「アイコン/使用例/基本アイコン/bell-off」と同じCSF形式とし、`layout: centered`で公開入口の実コンポーネントを1つ中央に表示します。`!autodocs`を指定します。
- Canvasに見出し、説明、独自の設定欄や枠、Props表、使用コード・コピー、比較表示、折りたたみ、関連資料一覧を置きません。
- 設定はStorybook標準のControlsとargsで管理します。変更は見本に反映され、URLから復元できます。UIからのストーリー保存は無効にします。
- Controlsと標準パネルの設定はbell-offと揃えます。表示目的のイベントやplay関数は追加しません。

| コンポーネント | Controls | 初期値 |
| --- | --- | --- |
| TIcon | framework・name・size・color | React・bell・24px・currentColor |
| TBrand | framework・size | React・32px |
| TLogo | framework・size・decorative | React・32px・false |

方式はReact・Vue・Astroの順とし、切り替えても他の設定を保持します。TIconの公開名は329種、サイズは16・20・24・32px、色は継承・ニュートラル・7色のプライマリーから選びます。色はbell-offと同じ既存トークンへのmappingで指定し、URLには選択肢のキーを保持します。TLogo・TBrandは32・64・128pxで、原本の固定配色と余白を維持します。

## 共通の描画処理

`components/component-story.ts`のrenderComponentStory・componentStoryParameters・frameworkControlを再利用します。`components/ComponentPreview.tsx`がReact・Vue・Astroの実コンポーネントを描画します。Storybook専用コードはアプリ向け公開入口からexportしません。

- args更新には同じReactのrootとVueアプリを使います。方式切り替え時は旧方式の表示を解放し、離脱時にReactのrootと内部Vueアプリを解放します。
- Astroは既存の生成済みHTMLとcreateAstroPreviewLoaderを利用します。SVGのID分離と親からの色継承を維持します。
- 読み込み中はrole=status、失敗時はrole=alertと「再試行」を表示します。正常時は見本だけに戻します。離脱後の古い応答は画面へ反映しません。
- 小さい画面でも実コンポーネントを縮小しません。既存トークンと公開APIに従います。

## 検証

390px・1440pxで中央の見本、Controlsの操作とキーボードフォーカス、方式切り替え時の設定保持、URL再読み込みを確認します。Astroの読み込み・失敗・再試行、Vueのアンマウント、moon/toolのクリッピング、静的Storybookでの3方式の表示も検証します。テスト・型検査・両ビルドはAGENTS.mdに従います。
