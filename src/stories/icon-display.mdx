# 共通表示ルール

329個のSVGは収録済みです。`bell` の詳細ルールは確定済み、それ以外の詳細ルールは案です。既存アプリへの適用は未実施です。

Vue向けの装飾アイコンは `TkwIcon` から利用できます。[Vueでの利用](?path=/docs/icons-vue--docs) に公開props・取り込み方法・実コンポーネントの確認ページをまとめています。

## 図形とサイズ

- 図形の管理元は `icons/` の原本SVGです。32×32の `viewBox`、縦横比、線幅、線端と角の形を維持します。
- 表示時は正方形のまま拡大・縮小し、個別に線幅を上書きしません。原本には線と塗りの両方が使われています。
- 16・20・24・32pxは比較用サイズです。一覧は原寸の32pxから確認します。全図柄を16pxで使えると保証するものではありません。
- 小さい表示で記号が判別しにくい場合は、サイズを上げるか、対象が分かる基本アイコンとラベルを使います。特に複合アイコンと枠付きアイコンの細部を確認してください。
- 小サイズの確認では、`circle-setting` や `square-setting` の歯車、`calendar-share` などの複合記号の細部が16pxで密集します。これらは24px以上を起点に確認し、必要なら32pxへ上げてください。
- アイコンの表示サイズとボタンの操作領域は別々に設計します。アイコン単体にフォーカスやクリック処理を付けず、リンクやボタンを使用します。

## 色と状態

- 表示用SVGの黒い線と塗りは `currentColor` で着色します。色は既存のカラートークンから指定し、値を複製しません。
- 通常の色背景には同色の `-on`、淡い背景には `-on-subtle` を組み合わせます。色の変更で図形の意味を変えません。
- `-off` は図柄が表す状態です。ボタンの `disabled`、選択状態、操作の可否とは分けて扱います。
- 成功・警告・失敗などの状態は、色だけでなく図柄と文言を併用します。

## アクセシビリティ

- 同じ意味のラベルと並べるSVGは `aria-hidden="true"` と `focusable="false"` で装飾として扱い、二重に読み上げさせません。
- アイコンだけのボタンやリンクには、その操作要素に「通知一覧を開く」などの読み上げ名を付けます。図柄名だけをラベルにしません。
- SVGだけで状態を伝えず、読み上げ可能なテキストを添えます。フォーカス表示は操作要素に設けます。
- 一覧の図柄は公開名ラベルを持つリンクです。サイズ見本は、個別ページにある公開名の装飾表示として扱います。

## 原本と表示用データ

原本のダウンロードでは、色・サイズ・IDを変換する前のSVGを取得します。Storybookで選んだ色とサイズは原本を書き換えません。クリッピングを持つ図柄は、同時表示時にIDが衝突しないよう、表示用の参照だけをインスタンスごとに変換します。
