# アイコンの用途一覧

**状態：SVG 制作済み・公開名と用途は案（ライブラリへの組み込み前）**

2026-10-02 時点の制作済み SVG をもとに、`tokiwagi-ui` の命名基準と用途を整理しています。提供フォルダ `icons` には、番号付きファイルを含めて **329 ファイル**あります。下表は全ファイルの図柄を確認し、公開名の案と元ファイル名を対応付けたものです。SVG の改名・取り込み、既存アプリへの置き換えはまだ行っていません。

## 命名基準

- 公開名は小文字のケバブケースとし、既存のアイコンセット名や `baseline`・`sharp`・`outline` などの識別子を含めない。
- 名前の順序は「対象または枠 → 操作・記号 → 方向 → 状態」を基本とする。例：`calendar-plus`、`circle-chevron-left`、`search-check-off`。パネルを閉じる名前は `panel-close-left`・`panel-close-right` とする。
- `calendar-` は予定、`task-` はタスクを操作する図柄。`circle-`・`square-`・`triangle-` は枠の形を表す。同じ記号でも、対象や枠が異なる図形は別名で管理する。
- 方向は制作済み系列に合わせる。山形の記号は `chevron-top`・`chevron-bottom`・`chevron-left`・`chevron-right`、並べ替えの矢印は `up`・`down`、点やドラッグハンドルの向きは `horizontal`・`vertical` とする。横三点は現行名の `ellipsis` を使う。
- 斜線付きの図柄には `-off` を付け、通常の図柄は状態接尾辞を省く。表示・非表示の対は `visibility-on`・`visibility-off` を使う。`-off` は状態を示す名前であり、ボタンの disabled 属性や操作可否を自動的に決めるものではない。
- 操作名は `setting`・`tool`・`login`・`logout` などに統一する。綴りは `information` とし、`infomation`・`settig` や単複の揺れを公開名に持ち込まない。
- `close` は閉じる・キャンセル、`delete` は削除、`minus` は除外・減少、`copy` は複製、`paperclip` は添付とする。図形が似ていても操作を混同しない。
- `recurring` は循環する二本の矢印による定期的な繰り返し、`repeat` は円弧状の一本の矢印による再実行・再読み込みとする。三点を線で結ぶ図柄の公開名は `share` とし、同期とは区別する。
- `success`・`warning`・`error`・`info` は表示文脈とセマンティックカラーの役割として扱う。公開名は `circle-check`・`triangle-information`・`circle-close`・`circle-information` などの図柄に対応させる。単純な選択・完了の印は `check`。`information` 系の実際の図柄は「!」なので、意味はラベルや説明文でも伝える。
- 書き出し時の連番 `-1`・`-2` は公開名に使わず、図柄から対象・操作・状態を判別する。元ファイル名との対応は下表で保持する。表にない組み合わせを制作済みとは扱わない。
- ブランドロゴは操作用アイコンと分け、`brand-` を付ける。今回の提供 SVG にはブランドロゴは含まれていない。

## アイコン名および用途

元ファイル名は提供フォルダ内の名前です。公開名は上記基準を適用した案で、ライブラリの実装済み API を意味しません。用途は UI で選ぶ際の目安です。カレンダー・タスク系列はその対象の操作、枠付き系列は同じ操作・状態の表示に使います。三角枠であることだけで警告を意味するわけではありません。

## 既存フロントエンドの参照 ID との対応

以下は 2026-09-27 の調査で確認した **54 種類の参照 ID** と直書き SVG の記録を引き継いだ移行案です。`tokiwa-calendar-frontend` の実装は変更していません。「未収録」は今回の提供 SVG に専用の図柄がない用途で、制作済み329個には含めません。

`panel-left` は左側パネル表示の候補です。`circle-mail` はメール一般の図柄なので、送信完了の意味は文言で補います。`loading` は専用のアニメーション表現が必要であり、`repeat` の再読み込み操作とは分けて扱います。

## 今回の SVG に含まれない追加候補

旧案のうち `calendar-today`・`external-link`・`home`・`user`・`users` は未収録です。`more-horizontal` / `more-vertical` は `ellipsis` / `ellipsis-vertical`、`drag-handle` は `grip-horizontal` / `grip-vertical`、`refresh` は `repeat` の用途として整理しました。旧 `sort-ascending` / `sort-descending` は対象に応じて文字・数値の並べ替え系列から選びます。

## 対象外

- `TokiwaIcon.vue` は装飾的な背景表現で、操作用アイコンではない。
- カレンダーのスクリーンショット・機能紹介画像・favicon はアイコン一覧に含めない。
- 色見本の記号や文字は、この一覧の参照 ID 数には含めない。
