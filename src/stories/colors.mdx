# カラーの使用ルール

Tokiwagi UI はライトモードを対象とします。白とニュートラルグレーを土台にし、プライマリー7色を対等な主役として扱います。特定の1色を常に優先しません。

色の値は `tokens/colors.css`、`tokens/secondary.css`、`tokens/semantic.css`、`tokens/neutrals.css` が唯一の定義元です。全93トークンを6桁HEXで管理します。値、見本、文字コントラストは各ストーリーで確認できます。

## 4つの系統

| 系統 | 数 | 用途 |
| --- | ---: | --- |
| プライマリー | 7色・42トークン | 主要操作、カテゴリ、選択状態。文脈に応じて選び、同じ対象には画面間で同じ色を使う。 |
| セカンダリー | 3色・18トークン | 装飾、分類、補助的な強調。状態の意味は持たせない。 |
| セマンティック | 4状態・24トークン | 成功、警告、エラー、情報を一貫した意味で伝える。 |
| ニュートラル | 9トークン | ページ・カードの背景、境界線、文字階層、無効状態。 |

## 共通の接尾辞

プライマリー、セカンダリー、セマンティックは同じ6トークンを持ちます。

| 接尾辞 | 用途 |
| --- | --- |
| なし | 通常の基準背景 |
| `-hover` | ホバー背景 |
| `-active` | 押下背景 |
| `-subtle` | 広い面や通知に使う淡い背景 |
| `-on` | 通常・ホバー・押下背景上の文字とアイコン |
| `-on-subtle` | 淡い背景上の文字とアイコン |

色のある背景には、同じ色の `-on` または `-on-subtle` を組み合わせます。ボタンのフォーカス表示と境界線はコンポーネントで別途設計します。

## 状態とアクセシビリティ

- 成功は完了・保存成功、警告は注意・要確認、エラーは失敗・入力不備、情報は案内・進行状況に使います。
- 状態を色だけで伝えず、アイコン、見出し、説明文を併用します。選択状態や操作領域にもラベルや印を併用します。
- 各色の通常・ホバー・押下と `-on`、`-subtle` と `-on-subtle` の組み合わせは、通常サイズの文字で4.5:1以上を目標とします。対象は56組です。任意の組み合わせに対する保証ではありません。
- ニュートラルの見出しには `900`、本文には `800`、補助テキストには `600` を基本として使います。`1000` は最大コントラストが必要な場合に限ります。

## 実装時の参照

CSS変数は `--tkw-color-primary-green` のように使用します。Tailwind CSS v4 の共有テーマでは `bg-tkw-primary-green`、`text-tkw-primary-green-on` のようなクラスを使えます。カラーの変更は CSS トークンを編集し、Storybook の見本とコントラスト表示で確認します。
