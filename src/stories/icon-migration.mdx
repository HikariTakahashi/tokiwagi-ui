# 既存フロントエンドの参照 ID との対応

以下は 2026-09-27 の調査で確認した **54 種類の参照 ID** と直書き SVG の記録を引き継いだ移行案です。`tokiwa-calendar-frontend` の実装は変更していません。「未収録」は今回の提供 SVG に専用の図柄がない用途で、制作済み329個には含めません。

[`panel-left`](?path=/docs/icons-panel-left--docs) は左側パネル表示の候補です。[`circle-mail`](?path=/docs/icons-circle-mail--docs) はメール一般の図柄なので、送信完了の意味は文言で補います。`loading` は専用のアニメーション表現が必要であり、[`repeat`](?path=/docs/icons-repeat--docs) の再読み込み操作とは分けて扱います。

## 今回の SVG に含まれない追加候補

旧案のうち `calendar-today`・`external-link`・`home`・`user`・`users` は未収録です。`more-horizontal` / `more-vertical` は [`ellipsis`](?path=/docs/icons-ellipsis--docs) / [`ellipsis-vertical`](?path=/docs/icons-ellipsis-vertical--docs)、`drag-handle` は [`grip-horizontal`](?path=/docs/icons-grip-horizontal--docs) / [`grip-vertical`](?path=/docs/icons-grip-vertical--docs)、`refresh` は [`repeat`](?path=/docs/icons-repeat--docs) の用途として整理しました。旧 `sort-ascending` / `sort-descending` は対象に応じて文字・数値の並べ替え系列から選びます。

## 対象外

- `TokiwaIcon.vue` は装飾的な背景表現で、操作用アイコンではない。
- カレンダーのスクリーンショット・機能紹介画像・favicon はアイコン一覧に含めない。
- 色見本の記号や文字は、この一覧の参照 ID 数には含めない。
