# code

ファイル：`code.svg` · 状態：詳細ルール案（ライブラリへの組み込み・既存画面への適用前）

## 概要

ソースコード、スクリプト、埋め込み情報などのコード表現を示す。

## 使用場面

- 「埋め込みコードを表示」：操作対象と実行結果が分かる場所で使用する。
- 「スクリプトを編集」：同じ部品では意味を固定し、別の操作を兼ねさせない。

## 状態の表し方

- 表示・編集・実行の操作を区別する。コードが存在することと実行可能であることを混同しない。
- アイコンの表示と実際の状態を一致させる。操作不可の場合は操作部品側で無効状態と必要な理由を示す。

## 使用しない場面

- 通常の文章編集、リンクのコピー、同期状態。
- 操作できない状態表示を、押せるボタンのように見せること。

## 表示とアクセシビリティ

- アイコンだけの操作には「埋め込みコードを表示」など、図形名ではなく操作目的が分かる名前を付ける。
- 「コード」だけでなく「埋め込みコードを表示」など操作目的を伝える。
- 初めて使う場所や意味が曖昧な場所ではテキストラベルを併記する。隣接テキストと同じ意味のアイコンは装飾として扱い、二重に読み上げさせない。
- 状態は色だけで区別せず、文言・図柄・操作部品の状態でも伝える。ツールチップだけに意味を依存させない。
- サイズ・色・余白・操作領域・フォーカス表示は共通のアイコン／ボタン規則に従う。線幅や縦横比を個別に変更せず、キーボードでも操作とフォーカス位置を確認できるようにする。

## 関連アイコンと使い分け

- [`code-off`](?path=/docs/icons-code-off--docs)：コード機能の停止・利用制限。構文エラーや実行失敗を意味しない。
- [`calendar-code`](?path=/docs/icons-calendar-code--docs)：予定を対象とすることを図柄でも示す場合。
- [`task-code`](?path=/docs/icons-task-code--docs)：タスクを対象とすることを図柄でも示す場合。
- [`edit`](?path=/docs/icons-edit--docs)：既存の内容を変更する。
- [`link`](?path=/docs/icons-link--docs)：関連付けやリンク先への移動。共有権限とは区別する。
- [`search-code`](?path=/docs/icons-search-code--docs)：コードやスクリプトを対象とする検索を表す。
